PUBLISH FREE WITH GITHUB PAGES
1. On a browser, sign in or create a GitHub account at https://github.com
2. Create a new PUBLIC repository, e.g. kolkata-garments-tech-site.
3. Upload the contents of this folder (not the ZIP itself): index.html, policies.html, contact.html, styles.css, README.txt.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish. The site URL will be shown in Settings → Pages, typically https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
7. Open that URL on your phone and test all links before giving it to PayU.
8. Keep the repository public for GitHub Free Pages. Do not upload identity documents, bank details, passwords, API keys, or customer data.

GitHub's official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages
